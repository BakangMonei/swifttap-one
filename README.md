# SwiftTap One

A next-generation digital payments infrastructure built for Botswana — extending formal financial access to every consumer and merchant through interoperable, cloud-native technology.

## Overview

SwiftTap One is a Botswana-based fintech building a modular, cloud-hosted digital payments platform for the Bank of Botswana Regulatory Sandbox. This repository contains the company profile website — a premium, futuristic landing page showcasing the platform’s capabilities, compliance frameworks, and vision for inclusive commerce.

## Tech Stack

- **HTML** — Semantic markup
- **CSS** — Custom design system, CSS variables, glassmorphism, 3D transforms
- **Tailwind CSS** — via CDN with shadcn-inspired theme
- **Vanilla JavaScript** — Scroll effects, animated counters, Intersection Observer
- **Fonts** — Plus Jakarta Sans, Sora, IBM Plex Mono

## Features

- Dark fintech-themed design with refined gradients and glassmorphism
- 3D spinning device elements (phone, ATM, card, QR code, POS terminal, receipt)
- Sticky navbar with scroll-state enhancement
- Scroll progress bar and back-to-top button
- Animated stat counters and staggered scroll reveals
- Responsive layout for desktop, tablet, and mobile
- `prefers-reduced-motion` support for accessibility

## Getting Started

The site is static — open `index.html` in a browser or serve it with any static file server.

```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve
```

Then visit `http://localhost:8000`.
